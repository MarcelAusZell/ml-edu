# ML EDU

## Install requirements for ML-EDU
- Node.js
- npm

## Install Setup for ML-EDU
````
npm install
````

## Starting ML-EDU
````
npm start
````

## Documentation
If you want to build upon this project, the best documentation you will find is in ````bachelorthesis.pdf````.\
In it, you will find a tutorial about SVGs, D3.js, as well as useful references and more.
